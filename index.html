Capabilities

Powerful Features

Everything you need for robust fake news detection

Advanced Preprocessing

URL removal, punctuation stripping, lowercasing, whitespace normalization, and email filtering for clean text input.

TF-IDF Vectorization

N-gram range (1-2), 5000 max features, sublinear TF scaling, and English stopword removal for optimal vector representation.

Sentiment Analysis

Built-in linguistic analyzer with polarity, subjectivity, emotional triggers, credibility markers, and sensationalism scoring.

4 ML Models

Logistic Regression, Random Forest, Support Vector Machine, and Gradient Boosting — all with class balancing and cross-validation.

Ensemble Consensus

Majority voting across all models with confidence scoring, risk assessment levels, and detailed per-model breakdowns.

Rich Metrics

Accuracy, Precision, Recall, F1-Score, ROC-AUC, Confusion Matrices, and 3-Fold Cross-Validation for robust evaluation.

Model Persistence

Save and load trained model bundles with Pickle. Export complete pipelines including vectorizer, scaler, and all classifiers.

Batch Processing

Analyze entire CSV datasets in one run. Automatic summary generation with fake vs real counts and percentage breakdowns.
